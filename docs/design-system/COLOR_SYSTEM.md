# EbroZone Color System

> This document defines the official color system for EbroZone Version 1.

The color palette is designed to create a modern, premium, and human-centered learning experience that reflects trust, confidence, and progress.

Rather than relying on strong colors everywhere, EbroZone uses color intentionally to guide attention, communicate meaning, and create an elegant visual hierarchy.

---

# Design Philosophy

Color should support the experience, never dominate it.

The interface should feel:

- Premium
- Modern
- Friendly
- Professional
- Calm
- Inspiring

Students should immediately feel they are entering a trusted learning environment.

---

# Brand Identity

The EbroZone visual identity is built around three core colors.

## Primary

Deep Blue

```text
#1E3A8A
```

Used for:

- Primary Buttons
- Main CTAs
- Active Navigation
- Links
- Important Actions

Represents:

- Trust
- Confidence
- Intelligence

---

## Secondary

Bright Blue

```text
#3B82F6
```

Used for:

- Interactive Elements
- Progress Indicators
- Selected States
- Icons

Represents:

- Growth
- Learning
- Energy

---

## Accent

Warm Gold

```text
#F59E0B
```

Used sparingly for:

- Achievements
- Milestones
- Premium Badges
- Success Celebrations

Represents:

- Achievement
- Excellence
- Motivation

Accent colors should never dominate the interface.

---

# Supporting Gradient

Modern gradients may be used only in marketing sections.

Primary Gradient

```text
#1E3A8A → #6366F1
```

Secondary Gradient

```text
#3B82F6 → #8B5CF6
```

Gradients should appear only in:

- Hero Backgrounds
- CTA Sections
- Decorative Elements

Avoid using gradients inside dashboards.

# Color Usage

## Marketing Pages

Marketing pages may include:

- Soft gradients
- Floating glows
- Light background shapes
- Decorative color transitions

The objective is to create emotion and excitement without sacrificing clarity.

---

## Dashboards

Dashboards should prioritize clarity.

Use:

- White backgrounds
- Light gray surfaces
- Blue highlights
- Minimal gradients

Productivity always comes before decoration.

---

# Shadows

Prefer soft shadows over heavy borders.

Cards should appear slightly elevated while maintaining a light and clean appearance.

Avoid harsh shadows.

---

# Accessibility

All colors must satisfy WCAG AA contrast standards.

Color must never be the only method of communicating information.

Icons, labels, and typography should always reinforce meaning.

---

# Dark Mode

Version 1 supports Dark Mode.

Dark Mode should:

- Preserve contrast
- Maintain the brand identity
- Avoid pure black backgrounds
- Use softer dark surfaces

The experience should feel elegant rather than dramatic.

---

# Future Expansion

Future versions may introduce:

- Seasonal Themes
- Event Themes
- Limited Student Themes

The core EbroZone palette should always remain consistent.

---

# Success Criteria

A successful color system ensures that:

- The platform feels premium and trustworthy.
- Marketing pages are visually engaging.
- Dashboards remain clean and productive.
- Color consistently guides user attention.
- The visual identity is immediately recognizable as EbroZone.
