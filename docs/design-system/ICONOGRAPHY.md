# EbroZone Iconography

> This document defines the official iconography system for EbroZone Version 1.

Icons should support communication, improve usability, and reinforce the platform's modern and professional identity. They should simplify the interface without becoming decorative distractions.

---

# Design Philosophy

Icons should be:

- Simple
- Consistent
- Recognizable
- Functional
- Minimal

Icons should explain the interface, not decorate it.

---

# Icon Library

The official icon library is:

## Lucide Icons

Reasons:

- Modern
- Lightweight
- Open Source
- Excellent React support
- Consistent visual style
- Perfect integration with shadcn/ui

No additional icon libraries should be used unless absolutely necessary.

---

# Icon Style

All icons should:

- Use rounded outlines.
- Maintain a consistent stroke width.
- Follow the Lucide design language.
- Match the surrounding typography.

Avoid mixing different icon styles.

---

# Icon Colors

Icons should inherit the color of nearby text whenever possible.

Primary icons:

Deep Blue

Secondary icons:

Slate Gray

Success:

Green

Warning:

Gold

Error:

Red

Icons should not introduce new colors outside the design system.

---

# Icon Usage

Use icons to:

- Improve navigation.
- Support buttons.
- Highlight features.
- Represent actions.
- Communicate status.

Avoid using icons when text alone is clearer.

---

# Illustrations

Illustrations should be used only in:

- Landing Page
- Empty States
- Onboarding
- Marketing Sections

Dashboards should rely primarily on clean UI components rather than illustrations.

---

# Photography

Photography is a core part of the EbroZone brand.

Use authentic, high-quality images of:

- Teachers
- Students
- Live Classes
- Learning Environments

Photography should always feel natural, welcoming, and professional.

Avoid generic stock photos whenever possible.

---

# Teacher Images

Teachers are one of the strongest visual elements of the platform.

Teacher images should:

- Be professionally lit.
- Use clean backgrounds.
- Maintain consistent framing.
- Show approachable facial expressions.
- Reinforce trust and confidence.

Hero sections may include subtle animations around teacher portraits to create a more engaging experience.

---

# Avatars

User avatars should:

- Be circular.
- Maintain consistent sizing.
- Support image and initials fallback.
- Display online status where appropriate.

Recommended sizes:

Small

```
32px
```

Medium

```
40px
```

Large

```
56px
```

---

# Decorative Graphics

Decorative elements should remain subtle.

Examples:

- Soft gradients
- Floating shapes
- Light glow effects
- Background patterns

Decoration should never compete with primary content.

---

# Accessibility

Icons must never be the only method of conveying meaning.

Every important icon should have:

- Text
- Tooltip
- Accessible label

where appropriate.

---

# Success Criteria

A successful iconography system ensures that:

- Icons improve usability.
- Photography strengthens trust.
- Visual elements remain consistent.
- The interface feels clean, modern, and unmistakably EbroZone.
