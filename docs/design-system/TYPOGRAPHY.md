# EbroZone Typography System

> This document defines the official typography system for EbroZone Version 1.

Typography should communicate confidence, clarity, and professionalism while remaining highly readable across all devices.

The platform uses a single font family with a clear hierarchy to create a clean and consistent experience.

---

# Design Philosophy

Typography should:

- Guide attention naturally.
- Improve readability.
- Reduce cognitive load.
- Create visual hierarchy.
- Reflect a premium educational brand.

Students should spend their attention on learning, not decoding the interface.

---

# Primary Font

## Inter

Inter is the official typeface for EbroZone.

Reasons:

- Excellent readability
- Modern appearance
- Outstanding web performance
- Great multilingual support
- Industry standard for SaaS products

Inter should be used throughout the entire platform.

# Typography Rules

Use:

- Large headlines
- Short paragraphs
- Strong visual hierarchy
- Plenty of whitespace

Avoid:

- Long text blocks
- Excessive bold text
- Multiple font families
- Decorative fonts

---

# Hero Copy Guidelines

The hero section is the first impression of EbroZone and should immediately communicate trust, confidence, and transformation.

Hero headlines should:

- Never exceed three lines.
- Focus on one clear promise.
- Use simple, conversational language.
- Inspire action without exaggeration.
- Be easy to understand within a few seconds.

Supporting text should:

- Expand on the main promise.
- Explain the value clearly.
- Remain concise and easy to scan.
- Reinforce the human-centered learning experience.

Call-to-action buttons should use direct and confident language.

Examples:

- Book a Free Consultation
- Start Your English Journey
- Find Your English Level

The goal of the hero is not to explain everything about EbroZone, but to encourage visitors to continue exploring the platform and take the first step toward becoming confident English communicators.

# Accessibility

Maintain sufficient contrast.

Avoid font sizes below 14px except for captions.

Typography should remain readable on mobile devices without zooming.

---

# Success Criteria

A successful typography system ensures that:

- Information is easy to scan.
- Headlines create impact.
- Body text remains comfortable to read.
- The interface feels modern and premium.
- Typography strengthens the EbroZone brand.
