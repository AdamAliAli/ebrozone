# EbroZone Teacher Dashboard Flow

> This document defines the complete teaching experience inside EbroZone Version 1.
>
> The Teacher Dashboard is designed to minimize administrative work so Ebro can focus on what matters most:
>
> **Helping students become confident English communicators.**
>
> Version 1 is intentionally simple, efficient, and built around Ebro's real daily workflow.

---

# Dashboard Philosophy

Every time Ebro logs in, he should immediately know:

- Who he is teaching today.
- When each class starts.
- Which students have upcoming sessions.
- Which homework is waiting to be reviewed.
- What his next action should be.

The dashboard should feel like a personal teaching assistant, not an administrative system.

# Schedule

View:

- Today's Classes
- Weekly Calendar
- Upcoming Consultations
- Student Time Zones
- Class Status

Available Actions:

- Start Class
- View Student Profile
- Reschedule Session
- Cancel Session (when necessary)

Scheduling should remain simple and visual.

---

# Student Management

Each student profile includes:

- Student Information
- Current Course
- English Level
- Attendance History
- Homework History
- Upcoming Sessions
- Contact Information

The objective is to give Ebro enough context before every lesson without overwhelming him.

---

# Live Classes

Before Class

Ebro can quickly review:

- Student Profile
- Current Course
- Previous Homework
- Upcoming Lesson

During Class

The dashboard provides quick access to:

- Meeting Link
- Lesson Resources
- Student Information

After Class

If needed, Ebro can:

- Upload Homework
- Upload Lesson Materials
- Send a Short Announcement

No lengthy reports or summaries are required in Version 1.

Teaching should remain the priority.

---

# Homework Management

Ebro can:

- Create Homework
- Attach PDFs or Worksheets
- Set Submission Deadlines
- Review Student Submissions
- Leave Feedback

Homework management should require only a few clicks.

---

# Lesson Resources

Organize learning materials by:

- Course
- Lesson
- Topic

Supported resources include:

- PDFs
- Worksheets
- Vocabulary Lists
- Practice Materials

Students automatically receive the correct resources for their course.

# Dashboard Principles

The Teacher Dashboard should always feel:

- Organized
- Fast
- Professional
- Calm
- Easy to navigate

Every feature should reduce administrative work and allow Ebro to spend more time teaching.

Version 1 intentionally avoids unnecessary complexity.

---

# Success Criteria

A successful Teacher Dashboard ensures that Ebro:

- Always knows what to do next.
- Can prepare for every lesson quickly.
- Manages students with minimal administrative effort.
- Keeps all teaching resources organized.
- Spends the majority of his time teaching rather than managing the platform.

The Teacher Dashboard should function as Ebro's daily workspace—simple, efficient, and focused entirely on delivering an exceptional learning experience.
