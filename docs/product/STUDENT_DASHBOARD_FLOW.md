# EbroZone Student Dashboard Flow

> This document defines the complete student experience after enrolling in EbroZone Version 1.
>
> The Student Dashboard is designed to help students stay organized, motivated, and confident throughout their learning journey.
>
> It should feel like a personal learning companion—not a traditional Learning Management System (LMS).

---

# Dashboard Philosophy

Every time a student logs in, they should immediately know:

- Where they are.
- What they need to do today.
- When their next class is.
- How they are progressing.
- What their next milestone is.

Students should never feel overwhelmed or lost.

The dashboard should replace uncertainty with clarity, confidence, and motivation.

# Dashboard Home

The dashboard welcomes the student personally.

Example:

> **Welcome back, Adam! 👋**

The homepage of the dashboard provides an instant overview of everything important.

## Dashboard Widgets

- 📅 Next Live Class
- 📚 Current Course
- 📝 Homework Status
- 📈 Your Confidence Journey
- 💬 Latest Messages
- 📆 Upcoming Bookings

The dashboard should answer one question:

> **"What should I focus on today?"**

---

# Upcoming Classes

Students can view:

- Date
- Time
- Time Zone
- Meeting Platform
- Join Meeting Button
- Class Status

### Available Actions

- Join Class
- Add to Calendar
- Request Rescheduling (if allowed)

Joining a class should require no more than one click.

---

# Live Class

When it's time for class, the dashboard highlights the active lesson.

Students see:

- Join Meeting
- Lesson Title
- Lesson Objectives
- Class Duration

The experience should feel effortless and stress-free.

---

# Class Summary

After every class, students receive a personalized summary including:

- Topics Covered
- Key Vocabulary
- Grammar Points
- Teacher Notes
- Homework
- Recommended Practice
- Next Class Date

This page reinforces learning while giving students a clear understanding of what they achieved and what comes next.

---

# Homework

Students can:

- View Homework Instructions
- Download Lesson Resources
- Upload Homework (if required)
- Check Submission Status
- View Deadlines

After review, students receive:

- Teacher Feedback
- Corrections
- Suggestions for Improvement

Homework should feel like another opportunity to grow—not like an exam.

---

# Your Confidence Journey ⭐

This is EbroZone's signature feature.

Instead of measuring only grammar or test scores, EbroZone tracks what matters most:

**The student's confidence in using English in real-life situations.**

Every lesson contributes to this journey.

Students can view:

- Confidence Progress
- Confidence Level
- Monthly Growth
- Teacher Feedback
- Personal Milestones

---

## Confidence Levels

Students gradually progress through meaningful milestones:

🌱 Building Confidence

🌿 Growing Confidence

⭐ Confident Speaker

🚀 Strong Communicator

👑 Confident English Communicator

These milestones celebrate personal growth rather than competition with others.

The goal is not to become perfect.

The goal is to become more confident with every conversation.

---

# Progress

Students should always see how far they have come.

Display:

- Attendance
- Completed Lessons
- Homework Completion
- Learning Milestones
- Personal Notes
- Learning Timeline

Students should compare themselves only with their previous progress.

Progress is personal.

# Dashboard Principles

The Student Dashboard should always feel:

- Personal
- Calm
- Organized
- Encouraging
- Easy to navigate
- Mobile-friendly

Every page should answer one simple question:

> **"What is the next best action for this student?"**

---

# Success Criteria

A successful Student Dashboard ensures that students:

- Never miss a class.
- Never lose track of homework.
- Always know what to do next.
- Feel supported throughout their learning journey.
- See meaningful progress over time.
- Become more confident after every lesson.

The dashboard should consistently reinforce the EbroZone promise:

> **Helping students become confident English communicators through a structured, supportive, and personalized learning experience.**
