# EbroZone Admin Dashboard Flow

> This document defines the administrative experience inside EbroZone Version 1.
>
> During Version 1, Ebro is both the Teacher and the Administrator.
>
> The Admin Dashboard is designed to help manage the business, maintain the platform, and support students efficiently without unnecessary complexity.

---

# Dashboard Philosophy

The Admin Dashboard is the operational control center of EbroZone.

Instead of focusing on technical administration alone, it should help answer one simple question:

> **"What needs my attention today?"**

The dashboard should provide a clear overview of the entire platform while allowing Ebro to quickly perform administrative tasks.

## Quick Actions

- Add New Course

## Today's Schedule

Provide a clear overview of today's activities.

Display:

- Upcoming Classes
- Upcoming Consultations
- Available Time Slots
- Schedule Conflicts (if any)

The administrator should immediately understand how the day is organized.

The dashboard should answer one question:

> **"What should I manage today?"**

---

# User Management

Manage all platform users.

Display:

- Students
- Teachers (Future)
- Administrators

For each user:

- Create Account (Enroll Student)
- View Profile
- Edit Information
- Resend Activation Email
- Deactivate Account
- Reactivate Account
- Reset Password (when necessary)

---

# Course Management

Manage all available courses.

- Master Conversation
- IELTS Preparation

- Slang & Everyday English

Available Actions:

- Create Course
- Edit Course
- Archive Course
- Update Course Information

# Consultation Requests

- Learning Goal

# Booking Management

View all scheduled sessions.

Manage:

- Student Requests

---

Manage:

- Hero Section
- About Ebro
- Courses

- FAQ

---

Manage student testimonials.

Actions:

- Edit

- Delete

---

# Languages

# Notifications

View important platform notifications.

Provide simple business insights.

- Consultation Conversion Rate

# Platform Settings

Manage platform configuration.

Examples:

- Business Information
- Contact Details
- Social Media Links
- Meeting Platform
- Notification Preferences
- Security Settings
- Language Settings

Version 1 should only include settings that are actually needed.

---

# Dashboard Principles

The Admin Dashboard should always feel:

- Organized
- Fast
- Professional
- Reliable
- Easy to understand

Administrative work should require as few clicks as possible.

---

# Success Criteria

A successful Admin Dashboard ensures that Ebro can:

- Monitor the health of the platform.
- Manage students efficiently.
- Organize consultations and classes.
- Keep website content up to date.
- Handle administrative work quickly.
- Spend more time teaching and less time managing.

The Admin Dashboard should function as the operational control center of EbroZone while remaining simple, scalable, and aligned with the philosophy of Version 1.
