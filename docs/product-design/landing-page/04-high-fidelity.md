# Landing Page High-Fidelity Layout

Version: v1.0

Status: Approved for UI Design

---

# Purpose

This document defines the final visual layout of the EbroZone landing page.

It specifies the composition, spacing, content hierarchy, imagery, and visual emphasis while remaining independent of implementation details.

The objective is to create a premium, modern, and human-centered experience that encourages visitors to book a consultation.

---

# Overall Visual Direction

The landing page should feel:

- Premium
- Trustworthy
- Human
- Modern
- Inspiring
- Calm

The design should resemble a premium educational platform rather than a traditional online course website.

---

# Visual Hierarchy

The visitor's attention should naturally follow this order:

1. Headline
2. Teacher
3. Primary CTA
4. Student Results
5. Learning Experience
6. Consultation Booking

Every section should have one clear visual focus.

---

# Hero Section

## Layout

Desktop

- 60% Content
- 40% Visual

The left side focuses on communication.

The right side focuses on trust.

---

## Left Content

Contains:

- Trust Badge
- Main Headline
- Supporting Paragraph
- Primary CTA
- Secondary CTA
- Student Statistics

Maximum content width:

600px

---

## Right Content

Contains:

- Professional teacher portrait
- Floating dashboard preview
- Student review card
- Lesson schedule widget
- Progress widget

Dashboard cards should overlap naturally without covering the teacher.

---

## Background

Background should include:

- Soft gradient
- Light abstract shapes
- Subtle glow effects

The background should enhance the hero without distracting from the content.

---

# Social Proof

Display four equally sized statistic cards.

Examples:

- Students
- Countries
- Success Rate
- Reviews

Cards should be highly readable.

# Meet Your Teacher

Desktop Layout

45% Image

55% Content

Content includes:

- Certifications

---

# A Day Inside an EbroZone Lesson

Display a horizontal timeline illustrating a typical lesson.

Each step contains:

- Screenshot
- Title
- One-line description

Suggested sequence:

- Join Live Lesson
- Warm Conversation
- Speaking Practice
- Teacher Feedback
- Homework
- Progress Tracking
- Celebrate Improvement

---

# Learning Journey

Display a vertical timeline.

Each step should connect visually.

Include simple icons to reinforce progression.

---

# Student Success Stories

Display testimonial cards inside a carousel.

Each card includes:

- Student photo
- Name
- Country
- Achievement
- Testimonial

Authenticity should take priority over marketing language.

---

# Free English Assessment

Center the section.

Contains:

- Illustration
- Heading
- Short description
- Primary CTA
- Secondary CTA

The assessment should always appear optional.

---

# Course Preview

Display course cards.

Each card includes:

- Course image
- Level
- Duration
- Description
- Learn More button

Cards should remain visually consistent.

---

# FAQ

Display an accordion.

Only one item should remain expanded at a time.

The interaction should feel clean and effortless.

---

# Final CTA

Create a large centered section containing:

- Motivational headline
- Supporting message
- Book Free Consultation button

This section should provide a strong conclusion to the page.

---

# Footer

Organize into multiple columns.

Suggested groups:

- Brand
- Navigation
- Courses
- Resources
- Contact

Bottom row:

- Copyright
- Privacy Policy
- Terms & Conditions
- Language Selector

---

# Layout Principles

The layout should:

- Maintain generous whitespace.
- Follow the Design System.
- Highlight the teacher naturally.
- Keep one primary action per section.
- Guide visitors toward booking.

---

# Success Criteria

The high-fidelity layout is successful when:

- The page feels premium.
- Visitors understand the value quickly.
- The teacher becomes the center of trust.
- Every section supports the conversion journey.
- The layout is ready for implementation.
