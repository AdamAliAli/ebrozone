# Landing Page User Flow

Version: v1.0

Status: Approved for Design

---

# Purpose

This document defines how visitors move through the EbroZone landing page until they complete the primary goal of booking a free consultation.

The user journey should feel natural, intuitive, and focused on building trust before asking for commitment.

---

# Primary Goal

Convert website visitors into consultation bookings.

---

# Decision Points

At any point, visitors may choose to:

- Book a consultation.
- Explore courses.
- Take the English assessment.
- Learn more about the teacher.
- Leave the website.

The landing page should consistently guide visitors toward booking while allowing exploration.

---

# Trust Journey

Every section answers one important question.

| Visitor Question | Section |
|------------------|---------|
| Can EbroZone help me? | Hero |
| Can I trust it? | Social Proof |
| Why is it different? | Why EbroZone |
| Who is my teacher? | Meet Your Teacher |
| What will lessons feel like? | A Day Inside an EbroZone Lesson |
| How does learning work? | Learning Journey |
| Have others succeeded? | Student Success Stories |
| What will I learn? | Course Preview |
| What if I have questions? | FAQ |
| What should I do next? | Final CTA |

---

# Conversion Points

Primary Conversion

- Book Free Consultation

Secondary Conversions

- Find Your English Level
- Explore Courses
- Contact EbroZone

---

# Friction Points

Potential concerns include:

- Is this suitable for my level?
- Can I trust the teacher?
- Will this fit my schedule?
- Is it worth the investment?

Each concern should be addressed before the visitor reaches the booking page.

---

# UX Principles

The user flow should:

- Feel natural.
- Minimize decision fatigue.
- Build trust progressively.
- Keep one primary objective.
- Make every next step obvious.

---

# Success Criteria

A successful user flow ensures that visitors:

- Understand the value of EbroZone.
- Build trust in the teacher.
- Feel confident about the learning journey.
- Reach the consultation page without hesitation.
