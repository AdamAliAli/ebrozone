# Layout Principles

The layout should:

- Follow a clear vertical reading flow.
- Maintain generous whitespace.
- Highlight one primary action per section.
- Keep the teacher as the central visual element.
- Support responsive layouts without structural changes.

---

# Success Criteria

A successful wireframe ensures that:

- Every section has a clear purpose.
- The page is easy to scan.
- The layout naturally guides users toward booking a consultation.
- The structure is ready for high-fidelity design.
