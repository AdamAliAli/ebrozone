# Landing Page Components

Version: v1.0

Status: Approved for Development

---

# Purpose

This document defines every reusable component required to build the EbroZone landing page.

The objective is to maximize component reuse, maintain consistency, and simplify future development.

Every component should follow the Design System.

---

# Component Philosophy

Every component should be:

- Reusable
- Modular
- Accessible
- Responsive
- Independent

Each component should have one clear responsibility.

# Shared Components

The following components should be reusable across the entire platform:

- Button
- Badge
- Section Heading
- Statistic Card
- Feature Card
- Course Card
- Testimonial Card
- Accordion
- Timeline
- Footer
- Navigation

Avoid creating duplicate components.

---

# Component Rules

All components must:

- Follow the Design System.
- Use Design Tokens.
- Support accessibility standards.
- Support responsive layouts.
- Be reusable throughout the platform.

---

# Success Criteria

The component architecture is successful when:

- Components are reusable.
- No duplicated functionality exists.
- New pages can reuse existing components.
- Development remains fast and consistent.
