# Landing Page Responsive Behavior

Version: v1.0

Status: Approved for Development

---

# Purpose

This document defines how the EbroZone landing page adapts across different devices while preserving usability, readability, and the overall user experience.

Global responsive rules are defined in the Design System. This document only covers page-specific behavior.

---

# Responsive Goals

The landing page should:

- Preserve the content hierarchy.
- Keep the primary CTA visible.
- Maintain readability.
- Prioritize fast loading on mobile devices.

---

# Navigation

Desktop

- Full navigation menu.
- Primary CTA always visible.

Tablet & Mobile

- Navigation collapses into a hamburger menu.
- CTA remains easily accessible.

---

# Hero Section

Desktop

- Two-column layout.
- Teacher image displayed beside the content.

Tablet

- Two-column layout with reduced spacing.
- Floating cards reposition automatically.

Mobile

- Single-column layout.
- Teacher image displayed above the content.
- CTA buttons become full width.

# Mobile Priorities

Mobile users should be able to:

- Read comfortably.
- Reach the primary CTA easily.
- Navigate with one hand.
- Complete the journey without unnecessary scrolling.

---

# Success Criteria

The responsive design is successful when:

- No functionality is lost.
- The consultation CTA remains easy to access.
- The layout remains clean across all supported devices.
- Performance remains fast on mobile networks.
