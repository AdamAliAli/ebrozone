# Teacher Dashboard User Flow

Version: v1.0

Status: Approved for Design

---

# Purpose

This document defines how teachers interact with the Teacher Dashboard during their daily workflow.

The dashboard should help teachers efficiently manage lessons, students, and teaching activities.

---

# Primary Goal

Help teachers complete their daily teaching responsibilities from one central workspace.

---

# Primary User Flow

Teacher

↓

Signs In

↓

Arrives at Dashboard Home

↓

Reviews Today's Overview

↓

Chooses Next Task

↓

Completes Teaching Activity

↓

Returns to Dashboard

---

# Common Teaching Flows

Teachers may:

- Join or start a lesson.
- Review today's schedule.
- View student progress.
- Assign homework.
- Respond to student messages.
- Upload learning resources.
- Review reports.

The dashboard should support these tasks with minimal navigation.

---

# Decision Points

From the dashboard, teachers can choose to:

- Open today's lessons.
- View students.
- Check assignments.
- Read messages.
- Upload resources.
- View reports.
- Manage account settings.

---

# User Questions

The dashboard should immediately answer:

- What do I need to do today?
- Which lesson is next?
- Which students need attention?
- Are there new messages?
- Are there assignments to review?

---

# Friction Points

Potential challenges include:

- Missing an upcoming lesson.
- Losing track of student progress.
- Spending too much time navigating.
- Missing important student communications.

The dashboard should surface priority tasks first.

---

# Success Criteria

The user flow is successful when:

- Teachers immediately know their priorities.
- Daily teaching tasks are easy to access.
- Common workflows require minimal navigation.
