# Student Dashboard User Flow

Version: v1.0

Status: Approved for Design

---

# Purpose

This document defines how students interact with the EbroZone Student Dashboard during their learning journey.

The dashboard should help students complete their daily learning tasks with minimal effort.

---

# Primary Goal

Help students access everything they need to learn English from one central place.

---

# Primary User Flow

Student

↓

Signs In

↓

Arrives at Dashboard Home

↓

Views Today's Overview

↓

Chooses Next Action

↓

Completes Learning Activity

↓

Returns to Dashboard

---

# Common Learning Flows

Students may:

- Join a live lesson.
- Complete homework.
- Review lesson materials.
- Track their progress.
- Read teacher announcements.
- Contact their teacher.
- Update their profile.

The dashboard should support these tasks with minimal navigation.

---

# Decision Points

From the dashboard, students can choose to:

- Join today's lesson.
- Open homework.
- View progress.
- Read messages.
- Check notifications.
- Open their profile.
- Change settings.

---

# User Questions

The dashboard should immediately answer:

- What should I do today?
- When is my next lesson?
- Do I have homework?
- How am I progressing?
- Has my teacher sent me anything new?

---

# Friction Points

Potential challenges include:

- Difficulty finding the next task.
- Missing an upcoming lesson.
- Forgetting homework.
- Feeling lost inside the platform.

The dashboard should reduce these issues by highlighting the most important information first.

---

# Success Criteria

The user flow is successful when:

- Students know what to do immediately after signing in.
- Daily learning tasks are easy to access.
- Students can complete their activities with minimal navigation.
