# Book Consultation High-Fidelity Layout

Version: v1.0

Status: Approved for UI Design

---

# Purpose

This document defines the visual composition of the Book Consultation page.

The page should feel welcoming, professional, and reassuring while encouraging visitors to complete the consultation request.

---

# Overall Design Direction

The page should feel:

- Professional
- Friendly
- Trustworthy
- Calm
- Minimal

The consultation form should be the visual focal point.

---

# Introduction Section

Contains:

- Headline
- Supporting description
- Trust message

The headline should immediately explain the value of the consultation.

---

# Consultation Benefits

Display three benefit cards.

Each card contains:

- Icon
- Title
- Short description

Benefits should reassure visitors that the consultation is valuable and pressure-free.

---

# Consultation Form

The form should appear inside a clean card.

Required fields should be visually distinguished from optional ones.

The primary action button should remain clearly visible.

The form should feel short and approachable.

---

# What Happens Next

Display a simple three-step timeline:

1. Submit Request
2. Ebro Contacts You
3. Free Consultation

This section should reduce uncertainty.

---

# FAQ

Display questions using an accordion.

The design should remain clean and easy to scan.

---

# Footer

Use the standard website footer defined in the Design System.

---

# Layout Principles

The layout should:

- Keep the form above the fold whenever possible.
- Guide attention naturally toward the submit button.
- Reinforce trust before asking for information.
- Avoid unnecessary visual distractions.

---

# Success Criteria

The page is successful when:

- Visitors understand the consultation process immediately.
- The form feels easy to complete.
- The page builds confidence before submission.
- The design is ready for implementation.
