# English Assessment Responsive Behavior

Version: v1.0

Status: Approved for Development

---

# Purpose

This document defines how the English Assessment adapts across different devices.

Only assessment-specific responsive behavior is documented here.

---

# Responsive Goals

The assessment should:

- Be comfortable to complete on any device.
- Keep one question visible at a time.
- Minimize scrolling.
- Maintain clear progress throughout the assessment.

---

# Navigation

Desktop

- Logo and Exit button displayed inline.

Tablet

- Compact navigation.

Mobile

- Simplified navigation with larger touch targets.

---

# Introduction

Desktop

- Centered assessment card.

Tablet

- Reduced spacing.

Mobile

- Full-width content with comfortable padding.

---

# Question Area

Desktop

- Centered question card with fixed reading width.

Tablet

- Slightly wider card.

Mobile

- Full-width question card.
- Large answer buttons.
- Comfortable spacing between options.

---

# Progress Bar

Desktop

- Full-width progress indicator above the question.

Mobile

- Compact progress indicator while remaining clearly visible.

---

# Navigation Controls

Desktop

- Previous and Next buttons displayed side by side.

Mobile

- Full-width buttons stacked vertically when necessary.

---

# Results

Desktop

- Results displayed in a responsive grid.

Mobile

- Results displayed as stacked cards.

---

# Consultation CTA

Desktop

- Centered call-to-action.

Mobile

- Full-width Book Consultation button.

---

# Mobile Priorities

Visitors should be able to:

- Answer questions comfortably.
- Understand their progress immediately.
- Complete the assessment without zooming.
- Book a consultation easily after viewing results.

---

# Success Criteria

Responsive behavior is successful when:

- The assessment is easy to complete on all supported devices.
- Navigation remains intuitive.
- No functionality is lost.
