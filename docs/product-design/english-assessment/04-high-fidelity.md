# English Assessment High-Fidelity Layout

Version: v1.0

Status: Approved for UI Design

---

# Purpose

This document defines the final visual composition of the English Assessment.

The assessment should feel friendly, encouraging, and engaging while helping visitors understand their current English level.

---

# Overall Design Direction

The assessment should feel:

- Friendly
- Professional
- Interactive
- Encouraging
- Focused

The interface should reduce anxiety and motivate visitors to complete the assessment.

---

# Layout

Desktop

- Centered assessment card.
- Progress bar at the top.
- Single question displayed at a time.

Tablet

- Full-width assessment card with reduced spacing.

Mobile

- Single-column layout.
- Large touch-friendly answer options.

---

# Introduction

Display:

- Assessment title.
- Short description.
- Estimated completion time.
- Start Assessment button.

Purpose:

Help visitors understand what to expect before they begin.

---

# Question Area

Display:

- Current question.
- Available answer options.
- Progress indicator.

Only one question should be visible at a time.

---

# Navigation

Display:

- Previous button.
- Next button.
- Finish button (on the last question).

Navigation should remain simple and predictable.

---

# Results

Display:

- Estimated English level.
- Strengths.
- Areas for improvement.
- Personalized recommendation.

Results should feel encouraging rather than judgmental.

---

# Consultation CTA

Display:

- Short motivational message.
- Book Free Consultation button.

The CTA should feel like a natural continuation of the assessment.

---

# Layout Principles

The layout should:

- Keep the visitor focused.
- Minimize distractions.
- Reinforce progress throughout the assessment.
- Follow the Design System consistently.

---

# Success Criteria

The layout is successful when:

- Visitors complete the assessment comfortably.
- Results are easy to understand.
- The transition to booking a consultation feels natural.
