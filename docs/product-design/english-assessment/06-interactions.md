# English Assessment Interactions

Version: v1.0

Status: Approved for Development

---

# Purpose

This document defines how visitors interact with the English Assessment.

It focuses on user actions and system feedback throughout the assessment experience.

---

# Interaction Principles

Every interaction should:

- Feel responsive.
- Encourage completion.
- Reduce uncertainty.
- Keep visitors focused on one question at a time.

---

# Starting the Assessment

Visitors can:

- Start the assessment.
- Exit before beginning.

Starting the assessment should initialize the first question immediately.

---

# Answering Questions

Visitors can:

- Select one answer.
- Change their answer before continuing.
- Move to the next question.

Only one answer may be selected for each question.

---

# Navigation

Visitors can:

- Go to the next question.
- Return to the previous question.
- Finish the assessment after the final question.

Progress should update immediately after each completed question.

---

# Progress Indicator

The progress bar should:

- Update after each answered question.
- Display the current question number.
- Clearly communicate remaining progress.

---

# Results

After completion:

- Calculate the estimated English level.
- Display strengths.
- Display improvement areas.
- Present a personalized recommendation.

Results should appear without requiring a page refresh.

---

# Consultation CTA

Visitors can:

- Book a free consultation.
- Return to the landing page.

The recommendation should naturally encourage the consultation without creating pressure.

---

# Error Handling

If the assessment cannot continue:

- Display a friendly message.
- Preserve completed answers.
- Allow the visitor to continue or retry.

---

# Accessibility

Support:

- Keyboard navigation.
- Visible focus indicators.
- Screen readers.
- Reduced Motion preferences.

---

# Success Criteria

Interactions are successful when:

- Visitors always understand the next step.
- Progress feels smooth.
- Completing the assessment is effortless.
- The transition to consultation feels natural.
