# English Assessment User Flow

Version: v1.0

Status: Approved for Design

---

# Purpose

This document defines how visitors interact with the English Assessment.

The assessment should be simple, engaging, and guide visitors toward booking a consultation.

---

# Primary Goal

Help visitors understand their English level and encourage them to continue their learning journey.

---

# Primary User Flow

Visitor

↓

Starts Assessment

↓

Answers Questions

↓

Views Progress

↓

Completes Assessment

↓

Receives Results

↓

Books Consultation (Optional)

---

# Alternative Flow

Visitor

↓

Starts Assessment

↓

Leaves Before Completion

↓

Returns Later

↓

Continues Assessment

↓

Views Results

---

# Decision Points

Visitors can:

- Continue to the next question.
- Go back to the previous question.
- Exit the assessment.
- Book a consultation after receiving results.

---

# User Questions

The assessment should answer:

- What is my current English level?
- What are my strengths?
- What should I improve?
- What should I do next?

---

# Friction Points

Potential concerns include:

- Assessment taking too long.
- Fear of getting answers wrong.
- Uncertainty about the results.

The assessment should reassure visitors that it is a learning tool, not an exam.

---

# Success Criteria

The user flow is successful when:

- Visitors complete the assessment.
- Results are easy to understand.
- Visitors feel motivated to continue learning.
- More visitors book consultations.
