# Live Learning System Specification

> This document defines how live learning works inside EbroZone Version 1.

The live learning system is designed around one-on-one sessions between Ebro and students.

The platform supports learning before, during, and after every lesson while keeping the experience simple and personal.

---

# Goals

The Live Learning System should:

- Make joining lessons effortless.
- Keep students organized.
- Support personalized learning.
- Keep lesson materials in one place.
- Minimize administrative work for Ebro.

---

# Lesson Types

Version 1 supports:

- One-to-One Live Classes
- Free Consultation Sessions

Future versions may support:

- Group Classes
- Workshops
- Recorded Lessons

---

# Lesson Flow

## Before the Lesson

Students can view:

- Lesson Date
- Lesson Time
- Time Zone
- Meeting Link
- Assigned Homework (if any)
- Lesson Resources (if provided)

Students receive reminder notifications before the lesson.

---

## During the Lesson

Students join with one click.

The platform displays:

- Meeting Link
- Lesson Title
- Teacher Name

Video conferencing is provided through Google Meet.

---

## After the Lesson

If applicable, Ebro can upload:

- Homework
- PDFs
- Worksheets
- Vocabulary Lists
- Additional Practice Materials

Students receive a notification when new materials are available.

Version 1 does not require class summaries after every lesson.

---

# Homework

Homework is optional.

When assigned, students can:

- View Instructions
- Download Resources
- Upload Completed Homework
- Check Submission Status

Teachers can:

- Review Homework
- Leave Feedback
- Mark Homework as Reviewed

---

# Lesson Resources

Supported resources include:

- PDF Documents
- Images
- Worksheets
- Vocabulary Lists
- Practice Exercises

Resources remain available from the Student Dashboard.

---

# Attendance

Attendance is tracked automatically.

Possible statuses:

- Present
- Absent
- Cancelled
- Rescheduled

Attendance contributes to the student's overall progress.

---

# Student Dashboard Integration

Students can:

- Join Upcoming Lessons
- View Homework
- Access Lesson Resources
- Review Attendance
- Track Upcoming Sessions

---

# Teacher Dashboard Integration

Ebro can:

- Start Lessons
- View Student Information
- Upload Homework
- Upload Lesson Resources
- Review Homework

The workflow should require as few clicks as possible.

---

# User Experience Rules

The Live Learning System should always feel:

- Simple
- Reliable
- Organized
- Personal

Students should never wonder:

- Where is my lesson?
- Where is my homework?
- Where are my resources?

Everything should be accessible from one place.

---

# Success Criteria

A successful Live Learning System ensures that:

- Students join classes effortlessly.
- Homework is easy to access and submit.
- Lesson resources remain organized.
- Ebro spends more time teaching than managing files.
- Every lesson feels like a natural continuation of the student's learning journey.
