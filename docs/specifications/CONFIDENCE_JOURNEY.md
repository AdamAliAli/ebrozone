# Confidence Journey Specification

> This document defines the Confidence Journey, EbroZone's signature feature.

The Confidence Journey helps students visualize their progress beyond grammar and vocabulary.

The goal is to encourage students, celebrate improvement, and reinforce EbroZone's mission of building confident English communicators.

---

# Goals

The Confidence Journey should:

- Motivate students.
- Celebrate personal progress.
- Encourage consistency.
- Reinforce confidence over perfection.
- Create a unique EbroZone experience.

---

# Philosophy

Learning English is not only about knowing more words.

It is about becoming more confident when using them.

Students should compare themselves only with who they were yesterday.

The Confidence Journey is personal.

It is never a competition.

---

# Confidence Levels

Students progress through five confidence stages:

🌱 Building Confidence

↓

🌿 Growing Confidence

↓

⭐ Confident Speaker

↓

🚀 Strong Communicator

↓

👑 Confident English Communicator

These stages represent personal growth rather than English proficiency.

---

# Progress Tracking

The journey displays:

- Current Confidence Level
- Confidence Progress
- Completed Lessons
- Attendance
- Learning Milestones

The dashboard should clearly show that progress is earned over time.

---

# Learning Milestones

Examples:

- First Lesson Completed
- First Homework Submitted
- Five Lessons Completed
- First Month of Learning
- Consistent Attendance
- Course Completed

Milestones celebrate effort and consistency rather than perfection.

---

# Student Dashboard

Students can always view:

- Current Confidence Level
- Learning Milestones
- Attendance
- Completed Lessons
- Upcoming Lessons

The Confidence Journey should be visible from the dashboard homepage.

---

# Teacher Role

The Confidence Journey is supported by Ebro through encouragement and consistent teaching.

Version 1 does not require manual confidence scoring after every lesson.

Student progress is reflected through learning activity and milestone completion.

---

# User Experience Rules

Students should always feel:

- Encouraged
- Motivated
- Supported
- Proud of their progress

The Confidence Journey should never make students feel judged or compared to others.

---

# Success Criteria

A successful Confidence Journey ensures that students:

- Return to continue learning.
- Feel motivated by their progress.
- Celebrate consistency.
- Build confidence throughout their learning journey.

The Confidence Journey should become one of the most recognizable features of EbroZone.
